# Contributing

[简体中文](CONTRIBUTING.md) · [English README](README.en.md)

1. Install dependencies as described in the README. Run `npm run build` and `npm test` before making changes.
2. Reproduce issues with original or redistributable material. Document the source and terms of any submitted example. Keep classroom uploads and local runtime data outside the repository.
3. Preserve clear user-facing task status, results, and errors. Identify affected tracks and verification steps for export or API changes.
4. Rebuild and run the smoke test before opening a pull request. For interface changes, include what you verified in both themes.

See [NOTICE.md](NOTICE.md) for source licensing and attribution.
