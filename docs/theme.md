# 工作台主题 / Workbench themes

[中文 README](../README.md) · [English README](../README.en.md)

顶部右侧的切换按钮可在明暗模式之间切换。自媒体、课上、登录页与成果面板共用主题。浏览器保留上次选择，首次打开使用深色。课件预览内的互动内容使用课件自身颜色。

The button at the top right switches between dark and light. It applies to both modules, sign-in, and result panels. The browser remembers the choice. Classroom artifacts have their own colors.

| 用途 / Role | 深色 / Dark | 浅色 / Light |
|---|---|---|
| 页面底色 / Page | `#14131A` | `#F0EDF5` |
| 正文 / Text | `#F0EDF5` | `#14131A` |
| 侧栏 / Sidebar | `#1A1A21` | `#E8E7EC` |
| 卡片 / Cards | `#23232B` | `#FCFBFD` |
| 主操作 / Primary action | `#B49AF4` | `#B49AF4` |
| 选中标记 / Selection | `#B49AF4` | `#563D83` |
